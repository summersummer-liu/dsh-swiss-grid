# Parameters — formats, grids, type scales (all in mm)

## 1. Units

| Unit | Value |
|---|---|
| 1 西塞罗 cicero (Cic.) | 12 pt = 4.51 mm |
| 1 点 point (book / Didot) | 0.376 mm |
| 1 mm | 2.66 pt |
| 1 pt (PostScript) | 0.3528 mm |
| 1 mm | 2.8346 pt |
| DIN A0 … A10 | A0 841×1189 → each next size is half the previous area |

Conversion used in this skill: **mm × 2.8346 = pt** (PostScript), except when reproducing the
book's Didot numbers (1 pt = 0.376 mm).

The 8-cell and 32-cell systems share exactly the same type area; one 8-cell cell = two 32-cell

## 5. Baseline-derived type scale

Rule: pick a baseline (cell ÷ 6 is the default for posters), then express every role as a
multiple of it. `assets/poster_builder.py` uses:

| role | multiple | A2 (baseline 8.65) | A4 (baseline 4.32) |
|---|---|---|---|
| Chinese title | fills all 4 columns (adaptive) | 84.0 (4-char) | 41.9 (4-char) |
| English title | 0.855 × baseline | 7.39 | 3.69 |
| tagline | 0.740 | 6.40 | 3.20 |
| body | 0.647 | 5.59 | 2.80 |
| date / masthead | 0.555 | 4.80 | 2.40 |
| section heading | 0.520 | 4.50 | 2.25 |
| info text | 0.393 | 3.40 | 1.70 |
| label | 0.358 | 3.10 | 1.55 |
| caption | 0.300 | 2.59 | 1.30 |
| footer display | 0.994 | 8.59 | 4.30 |

The Chinese title size is computed from its length so it fills the full 4-column measure:
`size = text_width / (n·(1+0.0635) − 0.0635)`, tracking = 6.35 % of the size. A 4-char A2
title ≈ 84 mm, an 8-char title ≈ 42 mm.

Use these as a starting point, then adjust for content and viewing distance. On a poster the
smallest legible details are ~2.5–3.5 mm cap height at 1–2 m viewing distance; on a book page
the body is 8–12 pt.

## 6. Grids for other formats

- **A4 book / report**: 8- or 12-cell grid; body 9/12 or 10/13; captions 7/8; headings in
  whole-line multiples (2 lines = 24 pt or 26 pt). Page numbers one empty line from the text.
- **A3 poster**: a2-32 numbers × 0.707; or use a3-32 preset directly.
- **A1 poster / exhibition board**: a1-32 preset; image cells 1–4 columns.
- **Square catalogue**: derive from the page, keep 8 or 12 cells; the square needs a wider
  outer margin to avoid a heavy block feel.
- **Exhibition wall**: cell = 150×300 cm board split 2×4; eye level 170 cm; title/text lines on
  the same baseline grid across all boards.

## 7. Margins and production

- Margin starter ratio: **head 1 : inner 1 : outer 2 : foot 3**. For perfect-bound books,
  inner margin must absorb the binding creep.
- Bleed: **3 mm** digital, **5 mm** offset/large format; cutting tolerance 1–3 mm.
- Crop marks: 2–3 mm long in the bleed band, offset ~0.4 mm from the trim corner.
- Page size in the PDF = trim + 2 × bleed (e.g. A2 420×594 → 426×600 mm).
- Registration/colour bars are the printer's job; the designer supplies the artwork.

## 8. Formula reference

```
k cells, h lines each, one empty line between:  N = k·h + (k−1)
cell height = integer × leading
baseline    = cell height / n   (n lines per cell; default poster n = 6)
column      = (text width − (cols−1) × gutter) / cols
caption occupies whole lines only
24 pt = 3×8 = 2×12 = 1×24   (8/12/24 pt alignment)
8-cell cell = 2 × 32-cell cell + gap   (153 pt = 2×69 + 15)
```
